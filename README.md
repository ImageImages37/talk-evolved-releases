# Talk Evolved — paquets

Client de bureau Nextcloud Talk (Windows, macOS, Linux) édité par ImageImages.

Ce dépôt ne contient que les **paquets publiés** : le code source est privé. Les applications installées y cherchent leurs mises à jour (fichier `latest.json` de la dernière release) et ne les acceptent que signées par la clé d'ImageImages.

Télécharger : [dernière version](https://github.com/ImageImages37/talk-evolved-releases/releases/latest).
